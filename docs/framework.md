# 评测框架

本框架用于评测“数据分析场景下的 Agent”，分为四个部分。

## 1. 题集

覆盖数据分析的典型任务类型：

- 取数：根据业务问题写出正确 SQL
- 清洗：处理缺失值、异常值、重复值
- 指标计算：同比、环比、留存、漏斗
- 归因分析：定位指标变化的原因
- 结论输出：把分析结果写成业务可读的结论

每道题包含：任务描述、输入数据、期望输出、判定标准。

## 2. 可执行验证器

用确定性检查判断 Agent 输出是否正确，而不是靠人主观打分。

- SQL 题：执行结果是否与标准答案一致
- 指标题：数值是否在允许误差内
- 归因题：是否命中预设的关键原因
- 结论题：是否包含必要要素（结论、依据、建议）

## 3. 复杂度分层

按任务难度分层，避免只测简单题。

- L1：单步操作，如简单查询
- L2：多步操作，如连接 + 聚合
- L3：需要业务判断，如口径选择
- L4：开放任务，如完整分析报告

## 4. 多 Agent 对比

在同一题集上比较不同 Agent 的表现。

- 指标：准确率、cost-of-pass、平均耗时
- 失败模式：取数错误、口径错误、结论空泛、幻觉
- 输出：对比表格 + 失败模式分类
